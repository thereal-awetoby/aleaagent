# Demo script (about 3 minutes)

1. **Problem (20s).** Agents answer from one source, hide disagreement, and nobody owns the mistake.
2. **Agents (20s).** Aggregator, Claim, Confessor. Point at the header: Zetaris, Meterless, Nightshift.
3. **Live Zetaris (30s).** Run with `SAMPLE_MODE=false` and `ZETARIS_ENDPOINT` set. Show the SQL under the sources table.
4. **Conflict (20s).** A bundle with spread above tolerance. Alea still drafts the claim at low confidence.
5. **Confession (30s).** Confessed. Open the confession card, then the Ledger button to show the H-MEM write.
6. **Refusal (30s).** Run the same shape again. Refused, citing the confession id, with the recalled memory.
7. **Close (20s).** Tracks, sponsors, repo link. Mention SAMPLE_MODE is the default and the live pass is in the video.
